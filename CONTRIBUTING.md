# ¿Cómo Contribuir?

¡Gracias por tu interés en contribuir a este proyecto! No importa si es tu primera vez haciendo un PR (Pull Request) o si eres un desarrollador senior, toda ayuda es bienvenida.

## El Proceso de Desarrollo (La regla de oro)

1. **Nunca hagas push directo a la rama `main`**.
2. **Usa Issues:** Antes de escribir código, abre un Issue explicando qué vas a hacer. Esto evita esfuerzos duplicados.
3. **Rama nueva:** Crea una rama desde `main` con un nombre descriptivo:
   `git checkout -b feature/mi-nueva-funcion` o `git checkout -b fix/error-login`
4. **Programa:** Escribe tu código. Si no sabes algo, pregunta en el Discord.
5. **Commits claros:** Haz commits que expliquen tu trabajo:
   `git commit -m "feat: añadida la función X"`
6. **Sube tu código:** `git push origin feature/mi-nueva-funcion`
7. **Abre un Pull Request:** Ve a GitHub y abre un PR. Llena la plantilla y espera a que un Mantenedor lo revise.

## ¿Dónde necesito ayuda?
Puedes buscar los Issues que tengan la etiqueta `good first issue` o `help wanted`. Son perfectos para empezar.

## ¿Dudas?
No tengas miedo de preguntar. Todos estamos aprendiendo. Únete a nuestro canal de Discord y habla directamente con el equipo.
