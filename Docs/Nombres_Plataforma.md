# Propuestas de Nombres para Plataforma Sambalab

Dado que la visión es evolucionar de un "entorno de entrenamiento" a un **Saas o Plataforma Open Source de Sambalab** para la preparación de entrevistas técnicas, aquí hay una lista de posibles nombres para el repositorio y el producto. 

## Enfoque: Infraestructura y Ecosistema
Nombres que suenan a herramienta fundacional o sistema principal.
- **`sambalab/tech-prep-os`** (Tech Prep Operating System - Da la sensación de una plataforma base donde se instalan distintas "pruebas").
- **`sambalab/interview-forge`** (La forja de entrevistas).
- **`sambalab/mock-hub`** (Centro de simulacros).
- **`sambalab/skill-sim`** (Skill Simulator).
- **`sambalab/pt-engine`** (Pruebas Técnicas Engine).

## Enfoque: Nombres de Marca (Más abstractos/Premium)
- **`sambalab/preptrack`** (El nombre actual es bueno, significa rastrear la preparación).
- **`sambalab/tech-arena`** (Arena técnica).
- **`sambalab/eval-matrix`** (Matriz de evaluación).
- **`sambalab/code-prove`** (Probar código).
- **`sambalab/interview-dojo`** (El dojo de las entrevistas).

## Enfoque: Académico / Laboratorio
- **`sambalab/dev-academy-core`**
- **`sambalab/tech-assessment-lab`**
- **`sambalab/interview-sandbox`**
- **`sambalab/sim-lab`**

> **Recomendación del Arquitecto:** Me inclino fuertemente por **`sambalab/tech-prep-os`** o **`sambalab/interview-forge`**. Ambos proyectan la idea de que esto no es solo un examen, sino una plataforma donde puedes *construir* (forge) o *ejecutar* (os) diferentes simulacros (InDesign, React, Python, etc.).
